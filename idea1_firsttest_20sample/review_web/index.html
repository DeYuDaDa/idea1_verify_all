使用说明

先看模型能获得的证据，判断问题是否有唯一、可推出的答案。不通过时选择或填写原因。参考答案默认隐藏；模型预测不显示。

键盘：Alt + ← / → 切题；Alt + 1 通过；Alt + 2 不通过。输入原因时不会触发切题快捷键。

审核自动存于当前浏览器；建议结束时导出 JSON。换电脑、浏览器或移动网页后，可用“恢复审核”导入。

打开一个批次，逐题查看图片与输入

选择含 data/input 和 data/media 的数据文件夹，或含 observations/attempts 的机制探测文件夹。文件只在本机浏览器中读取，不上传。
