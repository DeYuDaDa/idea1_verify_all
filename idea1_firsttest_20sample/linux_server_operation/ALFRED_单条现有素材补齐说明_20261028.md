## 如果某台机器已经解压过ALFRED Full

最省事的是只把这一个trial目录导出。需要的是原始`raw_images/`或对应视频；`traj_data.json`用于核对同一轨迹；如目录中有`problem*.pddl`或metadata也一起保留，但不要预先认定PDDL就是逐API步实际状态。

以下命令只读取已有单条目录并生成压缩包，不运行Unity、模型或新造任务。先把第一行替换成真实已有路径，再在有这些素材的Linux机器上运行。没有现有素材时不需要运行：

```bash
export ALFRED_EPISODE_DIR='/实际已解压的ALFRED完整目录/train/pick_and_place_with_movable_recep-Knife-Bowl-SideTable-28/trial_T20190907_074956_346598'

bash <<'BASH'
set -euo pipefail
: "${ALFRED_EPISODE_DIR:?请先指定已有的目标trial目录}"
episode_dir=$(realpath -- "$ALFRED_EPISODE_DIR")
expected_trial='trial_T20190907_074956_346598'
expected_task='pick_and_place_with_movable_recep-Knife-Bowl-SideTable-28'
if [[ ! -d "$episode_dir" || "$(basename -- "$episode_dir")" != "$expected_trial" || "$(basename -- "$(dirname -- "$episode_dir")")" != "$expected_task" ]]; then
  printf '%s\n' '目录不是指定Knife—Bowl—SideTable轨迹，停止。' >&2
  exit 1
fi
if ! find "$episode_dir" -type f \( -iname '*.png' -o -iname '*.jpg' -o -iname '*.jpeg' -o -iname '*.mp4' \) -print -quit | grep -q .; then
  printf '%s\n' '该目录没有实际图片/视频，仅JSON索引不足以补齐。' >&2
  exit 1
fi
data_root=${DATA_ROOT:-"$HOME/experiment_data/idea1_firsttest_20sample"}
export_dir="$data_root/existing_dataset_imports/alfred_knife"
mkdir -p -- "$export_dir"
stamp=$(date -u +%Y%m%dT%H%M%SZ)
archive="$export_dir/${stamp}_alfred_knife_existing.tar.gz"
tar -czf "$archive" -C "$(dirname -- "$(dirname -- "$episode_dir")")" "$expected_task/$expected_trial"
sha256sum "$archive" > "$archive.sha256"
printf '已导出：%s\n校验：%s.sha256\n' "$archive" "$archive"
BASH
```

预期得到同一trial的现有素材包及SHA256。它只是收集素材成功，不等于视觉可答性、动作成功和事实答案已经审核通过。

## 如果没有任何完整包来源

可以选择只重放这一条已有专家轨迹，额外保存RGB和metadata；这不需要设计新情节，但属于重新采证。它不能被称为原始演示PNG。

当前实验环境不能默认兼容：官方ALFRED依赖`ai2thor==2.1.0`，需要单独核对Unity build、官方场景恢复和动作执行路径。不能用当前版本直接改写目标ID来凑出成功记录，也不能静默修复失败动作。官方augmenter中动作前后Pass会推进物理时间，需沿用相应时序并让RGB与metadata同event对应。

本轮没有安装旧环境，也没有提供伪装成已验证的一键replay命令。实际准备这一步时，应先做独立的单轨迹采证脚本与环境检查，再由用户在Linux执行；不得启动全部ALFRED轨迹。

核心取证点是动作8完成后/动作9之前（刀已经在碗里的旧状态），以及动作9—17搬碗过程和17之后。需分别确认碗的新承载面、刀的世界/嵌套位置、刀—碗关系保持。若图片已经能唯一确定某事实，人工标注即可，不强制每个问题都依赖metadata。
