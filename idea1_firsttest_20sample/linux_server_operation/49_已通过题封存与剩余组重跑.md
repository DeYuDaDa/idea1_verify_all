## H01/H02如何原生添加

核对了当前 pinned commit `f0825767cd50d69f666c7f282e54abfe58f1e917` 的官方源码：

- `InitialRandomSpawn(numDuplicatesOfType=[...])` 能复制物品，但会涉及场景内其他可拾取物的重新摆放，并重新计算对象ID，故这里使用更局部的创建方式。
- `CreateObjectAtLocation` 按类型、位置、旋转、variation新增一个物品。这里使用 `forceAction=False`，位置候选来自已有物品与台面的原生包围盒；不是在metadata中虚构第二个ID。
- 每次只补必要数量；必须有原生成功回执、新的独立ID和所需属性，再经过4次原生Pass并核对台面双方的包含关系。失败就留证，不继续假定数量充足。
- 添加只在私有准备阶段，公开历史禁止创建、重排或坐标放置。原始库存和添加后的库存分别保留，生成包含 `native_inventory_preparation.json`。

官方来源：[创建action](https://github.com/allenai/ai2thor/blob/f0825767cd50d69f666c7f282e54abfe58f1e917/unity/Assets/Scripts/PhysicsRemoteFPSAgentController.cs#L6224-L6251)、[prefab与碰撞检查](https://github.com/allenai/ai2thor/blob/f0825767cd50d69f666c7f282e54abfe58f1e917/unity/Assets/Scripts/InstantiatePrefabTest.cs#L72-L118)、[随机化文档](https://ai2thor.allenai.org/ithor/documentation/objects/domain-randomization/)。源码支持不等于本机资源和摆放已通过；下一次原生运行检查这一步。
