# 闭源模型评测：先传共同静帧，视频作为附加条件

## 当前数据与建议

当前完整自然历史H01-1有397条模型可见帧、5个问题。它不是397张私有校准图；私有准备、程序检查表和完整原生metadata另存，不发送给模型。已认可H05-3有159条公开帧、4个问题。

建议先保留原始数据不动，另外定义两个带独立manifest的评测视图：

1. **完整视图**：使用已封存V输入的全部原始公开帧，作为当前任务的参照。每个物理序列只调用一次模型，统一回答其全部5题或4题，不按网页q001–q005重复发送同一组图。
2. **紧凑视图**：优先尝试每序列约40–80张，数量是目标预算而不是硬上限。任何必要证据或身份连续性会被删掉时，增加帧数，不能为了凑20/40张而使题不可答。

先用H01-1和H05-3比较完整/紧凑的答案及引用帧，再扩大到各四个变体。其余变体不能未经检查直接测模型，构造失败不能算模型失败。四个变体只是受控试验，不足以报告稳定的整体能力排行榜。

## 哪些帧必须保留

H01保留：两杯首次公开拿取的身份确认；三次接水各自的空杯、开水与入流水、装水后的杯口和归位；两次倾倒的有水、跨过倒空的真实旋转帧、首次空杯、扶正后空杯、归位；开启咖啡机；目标杯拿取后与入机前；真正入机的前后返回；固定观察窗口末状态；另一杯状态与位置的可追踪证据。

H05保留：土豆身份与初态；历史入炉、门关、是否开机、实际加热过程或关机等待；开门取出；已熟条件的自然冷却及公开室温前提；最后在内/外的位置证据；最后关门关机；目标开机、预定窗口与结果。

可以优先减少：长距离走路的重复视野、无关键对象变化的细小转身，以及同一事实清楚呈现后紧接着的重复视角。不能只抽每隔N帧，否则倾倒、改接关系、取放瞬间容易丢失；也不能只保留前后终态，让整个历史失去身份连续性。

每次拿取—移动—归位之间保留少量衔接帧。两只杯子外观相同，过度压缩移动段可能让“这还是哪只杯子”无法回答，因此身份连续性比强行减少到20张更重要。

检查点可以帮助建立候选帧清单，但这是人工设计事件边界辅助的选帧条件，应明确标为curated视图。不能把这种结果声称为模型自行从长视频寻找事件的能力，也不能拿它单独证明模型解决了长程检索。若比较压缩效果，另加同数量均匀抽帧作为对照，区分“少帧减负”和“选中了关键事件”。

## 保留原档案，另建可审计的API输入

每个评测视图保存原包SHA-256、公开sample ID、原始帧索引/哈希、所选索引、保留/删除理由和题目版本。选帧规则先固定，不能看某模型答错后为它单独补图，也不能按Gold选择只对正确答案有利的终态。

发送三家相同顺序、相同尺寸的图片及相同公开初态、规则和问题；模型只能看到普通帧编号，不看检查点通过/失败、原生动作转录、ID、坐标或隐藏答案。初态或首次拿取的身份定义按已公开文本保留。所有规则、历史前提和正式问题不能因省token被省略。

实际API请求可将路径、SHA、私有全局步等技术字段移到请求manifest，只向模型传公开语义文本、连续帧编号和图像块；这属于新评测输入版本，须记录准确投影规则和完整实际消息，不能覆盖或声称沿用了历史prepared_request的完全相同字节。用固定投影在三家复用。

输出先要求简短JSON：每题答案+最多两个证据帧编号。不要求长篇推理，先控制输出和推理预算；需要分析时再对坏例追加独立诊断调用，不混入主评测。

## 为什么主方案先不用视频

视频是容器，不保证更便宜，也不保证模型看到全部397个采样画面。供应商可能按默认FPS再次抽帧，漏掉快速倾倒和取放。当前模拟器动作步和Pass也不等于等长物理秒，不能把每张图硬编码为固定时长后声称是真实时间视频。

主比较用共同静帧，能明确证明每家获得了哪些证据。Gemini原生视频可以作为额外输入模式：单独记录编码、分辨率、所设FPS、处理模式、时间映射和usage，不能把不同输入条件产生的分差直接归因为模型能力。

这些只算视觉输入，不含文字、输出、推理、缓存和重试。不是套餐全包价，不是实际账单；具体模型ID和公开依据、原始官方链接见同目录 `frontier_visual_api_costs_20261029.md`，启动正式请求前再核对账户权限和当日价格。

首轮做两个已接受物理序列×三家模型×完整/紧凑两种视图，共12次请求，每次同时回答该序列所有问题。先拿到实际usage，再预算全组。这样输入开销大致是逐题单独发送的1/4–1/5，同时保留共享上下文条件；如担心多题相互提示，选定小子集逐题独立复核，而不是一开始重复付全部帧费。

Batch可在模型及账户支持时省费用；缓存必须实际命中才按缓存价算，不事先当成免费。记录快照模型ID、请求时间、参数、原始响应、usage及成本。模型名和价格会变化，本报告不是永久配置文件。
